# XAU Analyzer PRO — Мульти-ТФ аналитик для MetaTrader 5

## 📋 Описание

Профессиональный советник-аналитик для MetaTrader 5, который анализирует рынок на трёх таймфреймах (H1, H4, D1) одновременно, генерирует торговые сигналы на основе 10 индикаторов с весами и предоставляет визуальный интерфейс с 5 вкладками.

## 🎯 Основные возможности

- ✅ **Мульти-ТФ анализ**: одновременная работа на H1, H4, D1
- ✅ **10 индикаторов с весами**: EMA, MACD, RSI, ADX, Stochastic, CCI, Volumes, OBV, Bollinger Bands, ATR
- ✅ **Авто-оптимизация**: бэктест на истории с подбором оптимальных параметров
- ✅ **Отключаемые фильтры**: 7 фильтров точности (новости, волатильность, сессия, свечи, RSI, структура, запаздывание)
- ✅ **Динамический срок жизни**: сигнал живёт от 3 часов (H1) до 5 дней (D1) в зависимости от силы
- ✅ **Отложенные ордера**: BUY LIMIT/STOP, SELL LIMIT/STOP с правильным R:R ≥ 1:1.5
- ✅ **Визуальная панель**: 5 вкладок с полной информацией
- ✅ **Статистика и история**: автоматический подсчёт точности, сохранение в файлы
- ✅ **Push-уведомления**: мгновенные оповещения на телефон
- ✅ **Git-интеграция**: версия 1.0 готова к публикации

## 📊 Слои архитектуры

### СЛОЙ 1: Config.mqh
Все константы, пороги, веса, множители — в ОДНОМ месте. Изменил здесь — изменилось везде.

### СЛОЙ 2: DataStructures.mqh
Единые структуры данных: `IndicatorVotes`, `IndicatorParams`, `SignalRecord`, `SignalState`.

### СЛОЙ 3: Analyzer.mqh
**Одна функция** `AnalyzeSignal()` — используется и в реальном времени, и в бэктесте. Гарантия идентичности логики.

### СЛОЙ 4: SignalManager.mqh
**Единственный источник истины** о текущем сигнале. Хранит состояние: активен/исполнен/закрыт/аннулирован.

### СЛОЙ 5: Storage.mqh
Работа с файлами через SignalManager. Читает/пишет сигналы, результаты, статистику, историю.

### СЛОЙ 6: UI (вкладки)
**Только отображение**. Читает данные из SignalManager, никакой логики.

## 🎨 Вкладки панели

### 📊 АНАЛИЗ
- Таблица H1/H4/D1 с голосами 10 индикаторов
- Взвешенная сумма (Σ)
- Прогноз (количество свечей)
- Целевая цена
- Уровни Entry/SL/TP для каждого ТФ

### 🛡️ ФИЛЬТРЫ
- Статус 7 фильтров (✅/❌)
- Активные режимы (H1/H4/D1)
- Итоговый статус подтверждения
- Базовые правила

### 📍 УРОВНИ
- Рекомендуемые уровни активного режима
- Entry, SL, TP с R:R
- Структурные уровни (сопротивление/поддержка)
- Уровни других режимов

### 📈 СТАТИСТИКА
- Всего сигналов, верных, ошибок, аннулированных
- Точность в процентах
- Оценка качества (ОТЛИЧНО/ХОРОШО/НОРМАЛЬНО)
- Кнопки RESET и БЭКТЕСТ

### 📜 ИСТОРИЯ
- Последние 5 сигналов
- Время, ТФ, направление, вход, статус, движение
- Итоговая статистика по истории

## ⚙️ Настройки

### Параметры индикаторов (оптимизируются бэктестом)
- EMA: быстрый/медленный период
- RSI: период, перекупленность/перепроданность
- MACD: быстрый/медленный/сигнальный период
- ADX: период, порог силы тренда
- Stochastic: %K, %D, замедление
- CCI: период, уровень
- Bollinger Bands: период, отклонение
- ATR: период, множитель для SL
- Порог взвешенной суммы

### Отключаемые фильтры
- FilterLag: фильтр запаздывания (не ловить хвост)
- FilterStructure: фильтр структурных уровней
- FilterRSI: фильтр RSI (не в экстремуме)
- FilterCandle: фильтр свечного паттерна
- FilterSession: фильтр сессии (0-5 часов)
- FilterVolatility: фильтр волатильности
- FilterNews: фильтр новостей

### Режимы сигналов
- UseSignalH1: сигналы H1 (быстрые, 1-5 свечей)
- UseSignalH4: сигналы H4 (средние, 4-20 свечей)
- UseSignalD1: сигналы D1 (долгие, 1-10 дней)

## 🧪 Бэктест

- Проверка на истории (1000-5000 баров)
- Авто-оптимизация параметров (порог, ATR, EMA, RSI)
- Раздельная статистика по H1/H4/D1
- Учёт аннулированных сигналов
- Сохранение отчёта в CSV

## 📈 Логика сигналов

1. **Анализ**: 10 индикаторов голосуют, взвешенная сумма ≥ порога
2. **Фильтры**: проверка 7 условий (RSI, свечи, структура, запаздывание и т.д.)
3. **Уровни**: расчёт Entry/SL/TP с R:R ≥ 1:1.5
4. **Срок жизни**: динамический (3 часа для H1, 8-20 часов для H4, 2-5 дней для D1)
5. **Исполнение**: ожидание достижения Entry цены
6. **Результат**: проверка SL/TP на каждом тике

## 🚀 Установка

1. Скопируйте файлы в папку `MQL5/Experts/` и `MQL5/Include/`
2. Скомпилируйте `analizXepomanLight.mq5` (F7)
3. Прицепите советник на график
4. Настройте параметры (F7 → Входные параметры)
5. Запустите бэктест для оптимизации
6. Примените лучшие параметры

## 📝 Использование

1. Откройте вкладку 📊 АНАЛИЗ — смотрите сигналы по ТФ
2. Откройте вкладку 🛡️ ФИЛЬТРЫ — проверяйте фильтры
3. Откройте вкладку 📍 УРОВНИ — смотрите рекомендуемые уровни
4. Дождитесь сигнала — получите Push-уведомление
5. Откройте вкладку 📈 СТАТИСТИКА — смотрите точность
6. Запустите бэктест — оптимизируйте параметры

## 🐛 Известные проблемы

- Линии уровней могут перекрывать кнопки (решено через OBJPROP_ZORDER)
- При перезапуске советника восстанавливается последний активный сигнал из файла
